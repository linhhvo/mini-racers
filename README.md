# Set up steps
## 1. Install essential build tools and SFML (Ubuntu example):

```bash
sudo apt update
sudo apt install build-essential cmake libsfml-dev
```
## 2. Create build directory and generate build files
```bash
mkdir build
cd build
cmake ..
```
